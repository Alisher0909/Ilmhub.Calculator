# Calculator Loyihasi

- Bu loyiha — Matematik amallarni bajarish, natijalarni ko'rish, tarixni saqlash va imkonini beradi.

## Loyihaning vazifalari

- Foydalanuvchidan matematik ifodani olish
- Amal bajarish (qo'shish, ayirish, ko'paytirish, bo'lish, va hattoki qavsli ifodalarni hisoblash)
- Har bir hisoblash natijasini ekranga chiqarish
- Hisoblash tarixini saqlab borish (JSON faylga)
- Istalgan vaqtda tarixni ko'rish yoki o'chirish imkonini berish

## Asosiy funksiyalari

- `+` Qo'shish
- `-` Ayirish
- `*` Ko'paytirish
- `/` Bo'lish
- Qavsli ifodalarni to'g'ri tartibda hisoblash (`8 + 2 * (4 - 1)` kabi)
- Hisoblash tarixini ko'rish
- Tarixdan biror hisobni yoki barchasini o'chirish
- Barcha hisoblar JSON faylga saqlanadi
